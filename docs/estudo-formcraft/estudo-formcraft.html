O que você precisa fazer

  1. Publicar os commits. O push direto para main é bloqueado para mim, então fica com você. O GitHub Actions faz o deploy do site sozinho em seguida. 
    git -C "D:\Project in claude\FORMCRAFT\.claude\worktrees\documento-analise-publicacao-0bb328" push origin HEAD:main
  2. Publicar as regras do Storage uma vez, senão o envio de PDF é recusado. O bucket já existe; faltam só as regras (arquivo storage.rules, cada usuário lê e grava apenas a própria pasta). Rode na pasta do projeto com o Firebase CLI logado, ou cole o conteúdo em Firebase Console → Storage → Regras. 
    firebase deploy --only storage
  3. Testar com a sua conta depois do deploy: enviar um PDF em uma aula, abrir Tarefas, Inbox e Coleções. Se algo travar, a tela de erro nova tem "Detalhes técnicos"; me mande esse texto.

Filtrei pelo que faz sentido para um caderno pessoal de faculdade e referências, e deixei de fora o que só serve para loja ou carteira de cripto. O Mobbin no plano grátis mostra só duas telas por categoria; o resto vem das imagens que você mandou e da minha análise do app. A última imagem que você mandou é do v0 (da Vercel), não do Perplexity, mas a ideia de busca é a mesma.

Identidade visual: Fichário

Você disse que o site está com cara de inteligência artificial. Concordo, e dá para apontar o porquê: são as mesmas escolhas padrão de milhares de apps gerados.

  • Roxo #7c6ef7 sobre quase-preto. É a combinação mais comum de apps feitos com IA.
  • Emojis como ícones em menus, cards e botões, misturados com os ícones de linha do menu.
  • Logo ⬡: um hexágono genérico que não diz nada sobre o app.
  • Hero centralizado "O que você precisa agora?", com chips embaixo, igual a todo chat de IA.
  • Brilhos desfocados roxo e verde no fundo do login.
  • Fonte do sistema e o mesmo raio, borda e sombra em todos os blocos, sem hierarquia.

A proposta parte do que o FormCraft é: um fichário de estudante. Fichas de biblioteca, papel pautado e marca-texto viram a linguagem visual. O amarelo de marca-texto é a assinatura, usado só onde você marcaria algo num caderno: o termo encontrado na busca, o item selecionado, a próxima prova. Este documento inteiro já usa essa identidade, nos dois temas.
